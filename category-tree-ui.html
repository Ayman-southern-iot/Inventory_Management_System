Fixed vs. the previous version (each verified, not assumed):
  • Search now prunes correctly. Typing "esp32" shows only ESP32 and its ancestor path — not the entire Electronics branch. Previous version force-expanded the whole matched top-level branch regardless of which leaf actually matched.
  • Real keyboard navigation. ↑/↓ move a visual + ARIA cursor (aria-activedescendant) without moving real DOM focus off the search box — this follows the WAI-ARIA combobox pattern specifically so screen readers don't announce rows as blank mid-navigation. →/← expand/collapse or jump to child/parent, matching the standard ARIA treeview keyboard pattern. Home/End jump to first/last visible row.
  • Escape closes the panel (first press clears the search if non-empty, second press closes and returns focus to the trigger) instead of only clearing text.
  • Tabbing out now closes the panel via a focusout check, instead of staying open until an outside click.
  • Focus returns to the trigger button after a selection or on close — it no longer gets silently dropped into a hidden container.
  • ARIA roles added: combobox/tree/treeitem, aria-level, aria-expanded, aria-selected, plus a live region announcing match counts as you type.
  • Inputs are 16px, not 13.5px — under 16px, iOS Safari auto-zooms the viewport on focus and does not zoom back out on blur.
  • Stale selection is detected. If the previously selected category no longer exists in the data (e.g. deleted by another user), it resets to "All categories" on next open instead of showing a dead label forever.
