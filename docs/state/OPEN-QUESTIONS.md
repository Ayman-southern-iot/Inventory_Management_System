| OQ-30 | 🟠 | **Should `POST /boms` and `POST /boms/:id/void` carry `@Roles`, like every sibling route?** Found by a false-passing test while closing D-013. Both are genuinely enforced — `BomsService.assertCanGenerate` / `assertCanVoid` refuse anyone without INVENTORY_MANAGER or ADMIN — so this is **not a hole**, and `permissions-non-admin.int-spec.ts` proves both refuse with 403. The difference is *when*: Nest runs guards before pipes, so every other route refuses before validation, while these two validate first. An unauthorised caller sending a malformed body therefore gets a 400 describing the payload shape rather than a 403. Adding `@Roles` touches permissions, which is a STOP, so it is recorded rather than done. | Leave as-is; it is a real control, just at a different layer. ## Resolved

- **OQ-26 — May an approver hold more than one live delegation?** → **No, one at a time.**
  Ayman's ruling 2026-08-23; shipped in `9f84f24` with a guard and a partial unique index. Two
  people simultaneously holding one approver's authority means an approval either could action,
  with nothing on the record saying which the approver meant.
- **OQ-27 — Does "Approved" mean currently or ever approved?** → **Currently.** Ayman's ruling
  2026-08-23; shipped in `5075895`, pinned by `APPROVAL_STANDING_STATUSES` and a test in
  `10d6283`. Accounts cares about money that can still be spent.
- **OQ-28 — Remove the dead `BOM_OVER_BUDGET_TOLERANCE_PCT`?** → **Removed.** Ayman's ruling
  2026-08-23; shipped in `9c562a1`. An admin could change a control that governed nothing.
- **OQ-29 — May approvers list the users they can delegate to?** → **Yes**, via
  `GET /users/selectable?role=`. Ayman's ruling 2026-08-23; shipped in `9f84f24`, serving both
  the delegate picker and the borrow-to-user picker (OQ-22) from one endpoint.
- **D-006 — Are the request-level fields mandatory?** → **Department, approval deadline and
  reason are required at submit; project stays optional.** Ayman's ruling 2026-08-26; shipped in
  `8ab180d`. Never at save: a draft is allowed to be half-finished. Full reasoning in
  `DECISIONS.md`. A requisition with **no project means personal development** (`5d5eef6`),
  which is an answer rather than a blank, so it is a label over a null `project_id` and not a
  seeded Project row.
- **EX-02 — inventory records export.** → **Built** in `3323e7f`. This was the last REQUIRED
  obligation in the requirements document with no implementation at all; §10 asks for the BOM
  *and* inventory records as PDF, and only the BOM half had shipped.

- **OQ-01 — Below the 15,000 BDT threshold, how many approvers?** → **1.** At or above the
  threshold it stays 2. Both are `app_settings` values, so the counts change without a
  redeploy. Answered by the user 2026-07-29.
- **OQ-02 — Are Approver 1 and 2 fixed company-wide or per department?** → **Per-department
  override**, on top of a company-wide default. Already modelled that way in `approver_slots`
  (a null `department_id` is the global default), so no migration was needed. Answered by the
  user 2026-07-29.

- **OQ-04 — What does the IM's edit on an approved borrow do once the item has left?** →
  Implemented as the working assumption and left open for confirmation: revert to PENDING is
  offered only while nothing has been returned and the item has not physically gone. After
  issue the correct action is a return, not an edit.
- **OQ-09 — Do projects need a code, owner, or budget?** → Name only, with a case-insensitive
  duplicate-name warning the user may override. A code, owner or budget would be additive
  columns, so the minimum costs nothing later.

- **OQ-03 — Do laptops need serial-level tracking?** → **No.** Quantity-based only. The
  `asset_units` layer stays dormant in the schema so it can be switched on with a migration
  if that ever changes. Answered by the user 2026-07-28.
- **OQ-08 — Is consumable a product flag or a per-borrow choice?** → **Both.** The product
  carries a default (`default_returnable`) and the borrow form may override it per line.
  Handles the cable that is usually consumed but occasionally returned, without needing an
  admin to edit the catalogue. Answered by the user 2026-07-28.
